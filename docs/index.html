Audit who receives the scarce slots.

RIDI is a research toolkit for allocation identity in capacity-limited AI: finite queues, shortlists, action sets and context windows.

Current manuscriptIdentical audits can yield different AI decisions. The central RAG experiment holds the complete declared retrieval audit exactly fixed while changing metric-zero passage identities.

1. Scientific object

Performance, calibration, group fairness and robustness remain necessary. Allocation identity asks a separate question at the score-to-action boundary:

Which identities receive the finite action — and is that membership identified by the audit?

The claim is not that every audit is insufficient. A sufficiently fine or explicitly identity-aware audit can identify membership. The empirical question is whether standard declared audits leave meaningful behavioral variation inside their audit-equivalence classes.

2. Quickstart

python -m pip install "git+https://github.com/adeebnoor/ridi.git"
import pandas as pd from ridi_audit import audit before = pd.read_csv("before.csv") after = pd.read_csv("after.csv") report = audit(before, after, k=[10, 50, 100]) print(report) controlled = report.control(k=100, eta=0.001) print(controlled["avoidable_turnover_fraction"])

Inputs need the same unique candidate identities and a score column; row order may differ. See the Python API and 60-second Quick Start.

3. What the API returns

FieldMeaning
changed_slotsHow many baseline top-k identities leave the selected set.
overlapHow many selected identities remain shared.
ridiJaccard distance between the equal-capacity selected sets.
global_spearmanWhole-universe rank agreement, reported alongside rather than substituted for finite membership.
margin_certifiedWhether the sufficient gamma_k > 2*epsilon zero-turnover certificate fires.

report.control(k=..., eta=...) computes the exact minimum-turnover solution satisfying an explicit updated-score utility-regret budget.

4. Design a study that can teach us something

DesignStrong useMain caution
Version-to-versionModel, data, ontology or pipeline updatesDo not attribute every observed change to one mechanism
Within-version controlEstimate ordinary temporal churnMatch interval and data-generating process
Representation interventionTest whether representation alone moves identitiesFreeze evidence, capacity and scoring logic
Exact audit-equivalence testAsk whether behavior is invariant inside a declared audit classDefine the audit before constructing alternatives
Prospective outcome gateCheck whether identity control preserves application valueLock endpoint, timing and capacity in advance
Boundary / null studyFind when identity adds no informationRetain nulls rather than redefining the claim

7. Scientific boundaries

Allocation identity does not by itself establish harm, benefit, fairness, correctness or model superiority. Metric-zero means zero benchmark relevance, not semantic irrelevance. The sufficient margin certificate is not necessary: unresolved cases are not predictions of instability. Identity preservation is only useful inside an explicit utility- or outcome-checked budget.

A good falsification is a contribution.Registered RxNorm and Open Targets failures are retained precisely because the goal is to establish the boundary of the phenomenon rather than manufacture positive turnover.
