# Reproducibility: "Identical relevance grades cannot certify retrieval-augmented AI answers"

The data, frozen analysis scripts, receipts and commercial-replication records for this manuscript are in the Source Data that accompany the submission (package v54, 13 November 2026). The analysis code is in its `code/` folder: `check_holdout.py` replays the registered held-out analysis, `holdout_analysis.py` is the frozen H1–H4 script, `theory_checks_v42.py` checks Proposition 1, and the figure scripts rebuild Figures 1–4 and Supplementary Figures 1–2. The README inside the Source Data lists every file and command, and the items held by the author for editors and reviewers.

Registrations: RIDI-CONFIRM https://osf.io/794p5/; RIDI-CONFIRM-C https://osf.io/anbjd/ (DOI 10.17605/OSF.IO/ANBJD). The companion tool is https://github.com/adeebnoor/ridi-check (archived snapshot https://doi.org/10.5281/zenodo.24193755).

The manuscript is unpublished and has not been peer reviewed. This folder will hold the code and data directly once the manuscript is published.
