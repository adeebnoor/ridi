We study how computational systems represent evidence, make inferences, explain predictions, and ultimately decide who receives action.

Three questions drive the research

A coherent programme, not a collection of projects.

01 · KNOWLEDGE

What does the system know?

How should fragmented evidence be represented and integrated so that computation can reason over it? Bioinformatics, Semantic Web, ontologies and biomedical knowledge integration.

02 · EXPLANATION

Why does it make this prediction?

Can predictive systems expose mechanisms rather than only scores? Drug safety, mechanistic inference, ontology-enhanced learning and interpretable AI.

03 · ACTION

Who ultimately receives the action?

When scores become finite queues, shortlists or interventions, what must evaluation report about the identities that actually receive scarce action?

RIDI · flagship project

Same audit. Different identities.

A system can pass the same reported aggregate audit while acting on different entities.

RIDI studies allocation identity in capacity-limited AI. It asks which entities receive finite action, which identities change across versions, and when that information is not recoverable from the conventional audit alone.
