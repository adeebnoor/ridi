See who changed when the metrics did not.

RIDI audits allocation identity: the people, documents, alerts, vulnerabilities or cases that actually occupy a finite queue, shortlist or context window.

The motivating result is simple: an evaluation can remain exactly unchanged while the finite allocation changes—and the downstream AI decision can change with it.

Scores available?

Go from audit to exact turnover control.

from ridi_audit import audit report = audit(before, after, k=[10, 50, 100]) controlled = report.control(k=100, eta=0.001)

audit() adds deterministic top-k selection, changed slots, RIDI, rank agreement and a sufficient stability certificate. control() computes the exact minimum-turnover allocation inside an explicit updated-score utility-regret budget—without retraining.
