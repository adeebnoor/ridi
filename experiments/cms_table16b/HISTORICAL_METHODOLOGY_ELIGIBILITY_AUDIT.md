# CMS HVBP historical methodology eligibility audit (FY2017–FY2021)

Purpose: screen consecutive pre-COVID fiscal-year pairs before acquiring historical hospital-level TPS data. A pair was eligible only if official CMS records supported the same measure set, domain structure/weights, and material performance-period/scoring definitions.

| Pair | Eligibility | Reason |
|---|---|---|
| FY2017→FY2018 | Ineligible | Domain structure/weights and measure set changed. |
| FY2018→FY2019 | Ineligible | Measure set changed: PSI-90 removed from Safety and THA/TKA complication added to Clinical Care for FY2019. |
| FY2019→FY2020 | Ineligible under strict invariance | Four 25% domains persisted, but the THA/TKA complication performance period changed from 30 to 36 months. |
| FY2020→FY2021 | Ineligible | Scoring inputs/measure set changed, including pneumonia-cohort/payment-measure changes and COPD mortality adoption. |

Conclusion: **no FY2017–FY2021 consecutive pair qualified**, so no historical hospital-level TPS data were acquired or pooled with the current FY2024→FY2026 panel.

## FY2022–FY2023 discontinuity

CMS did not calculate a TPS for FY2022 or FY2023 after measure suppressions/pauses. CMS IPPS file pages also state that Table 16B was not necessary in either year. These fiscal years are therefore recorded as a documented scoring-regime discontinuity, not silently bridged into a continuous panel.
