# Security policy

`ridi-audit` is research software and is not clinical decision-support software. Do not use it as a substitute for domain validation, regulatory review or professional judgment.

Do not open a public issue for a vulnerability that could expose restricted data or compromise a deployed system. Contact the repository owner privately through the institutional address listed on the author's ORCID profile and include the affected version, impact and minimal reproduction.

Version 1.x receives correctness and security fixes. Dependencies are intentionally small and continuous integration tests supported Python versions.
